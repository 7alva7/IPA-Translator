# Word IPA

Description

此開源項目爲粵語（廣東話/香港話）標注國際音標，支援粵拼及萬國音標。

This open-source project adds IPA to Cantonese / Yueyu / Guangdonghua, supporting Jyutping and International Phonetic Alphabet.
