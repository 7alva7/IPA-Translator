# Word IPA

Description

Đây là dự án mã nguồn mở chuyển phiên tiếng Việt (Tiếng Việt) sang phiên âm IPA, hỗ trợ phương ngữ miền Nam.

This open-source project converts Vietnamese (Tiếng Việt) to IPA, supporting Southern dialect.
